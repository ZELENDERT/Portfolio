📋Задача от заказчика

Заказчик занимается ВКонтакте-ролевой игрой. У него уже был работающий бот (~12 000 строк Python), написанный другим разработчиком. Нужно было добавить три крупных механики, которых не хватало для полноценной игры.

Проект был передан без сопровождения, только ссылка на GitHub. Нужно было самостоятельно разобраться в архитектуре чужого кода, не сломать ничего что уже работало — и дописать всё новое аккуратно в том же стиле.

⚙️Что было реализовано

1

Система аукционов с двумя режимами

Публичный аукцион — юзербот публикует пост на стене группы, ставки принимаются через комментарии в формате «ставка 500». Закрытый — бот рассылает приглашения в личные сообщения по фильтрам фракции и репутации. Автозавершение по таймеру через asyncio, уведомления победителю и создателю, проверка баланса при ставке.

2

Обработчик комментариев к постам (wall_reply_new)

Добавлен raw-event хэндлер который ловит все новые комментарии к постам группы и автоматически распознаёт ставки в аукционах. Ничего не ломает в существующей логике — просто добавлен в конец group_events.py.

3

POV-режим (от первого лица) с судейской панелью

Судьи и администраторы могут переводить игроков в POV-режим — поодиночке, по профессии или всех сразу. Игрок в POV общается только через юзербота (Сирену). Игрок может сам включить режим через настройки.

4

Четыре текстовых эффекта для POV

При пересылке сообщения — текст автоматически искажается в зависимости от дебаффа на получателе: Ограниченная видимость (часть нарратива замазана), Контузия (буквы перемешаны), Слепота (только прямая речь), Глухота (речь замазана, нарратив виден).

5

Антиспам-фильтр для POV-сообщений

Минимум 300 символов без пробелов, проверка на однотипные повторяющиеся слова, фильтр команд бота. При отказе игрок получает точное количество недостающих символов.

6

Режим скрытности [скрытность]

Если игрок добавляет тег [скрытность] в POV-сообщение — оно уходит только судьям и администраторам, остальные игроки его не видят. Тег автоматически очищается из текста перед отправкой.

7

Секретные разделы анкеты с контролем доступа

Игрок может добавить в анкету скрытые особенности, биографию, характер и мотивы. Доступ ограничивается по фракции + минимальной репутации или по профессии. При просмотре чужой анкеты секретные разделы подтягиваются автоматически с проверкой прав — всё встроено в существующую функцию loads_form.

service/pov_effects.py — эффект «Слепота» и диспетчер 
def apply_blindness(text: str) -> str:
    """
    «Слепота»: оставляем только прямую речь.
    Если речи нет — «Вы ничего не видите.»
    """
    quotes = re.findall(r'^\s*[-—]\s*(.*)$', text, re.MULTILINE)
    if quotes:
        return '\n'.join(f'— {q}' for q in quotes)
    return 'Вы ничего не видите.'


def apply_effect(text: str, effect_name: str) -> str:
    """Применяет нужный эффект по имени дебаффа."""
    effects = {
        'limited_visibility': apply_limited_visibility,
        'concussion':         apply_concussion,
        'blindness':          apply_blindness,
        'deafness':           apply_deafness,
    }
    fn = effects.get(effect_name)
    if fn is None:
        return text  # неизвестный эффект — текст без изменений
    return fn(text)

@user_bot.on.private_message()
async def pov_userbot_message(m: Message):
    if not m.from_id or m.from_id < 0:
        return

    pov_mode = await db.select([db.User.pov_mode])\
        .where(db.User.user_id == m.from_id).gino.scalar()

    if not pov_mode:
        return  # не в POV — хэндлер не вмешивается

    text = m.text or ''

    # Режим скрытности: только для судей
    if '[скрытность]' in text.lower():
        clean_text = text.replace('[скрытность]', '').strip()
        await forward_pov_message_to_judges(m.from_id, clean_text)
        return

    # Антиспам: минимум 300 символов без пробелов

                f'Нужно не менее 300 символов без пробелов.'
            ),
            random_id=0
        )
        return

async def _finish_auction(auction_id: int):
    """Завершает аукцион: победитель, уведомления, пост на стене."""
    auction = await db.Auction.get(auction_id)
    if not auction or auction.finished:
        return

    top = await _get_top_bet(auction_id)
    winner_form_id = top[0] if top else None

    await db.Auction.update.values(
        finished=True,
        winner_form_id=winner_form_id
    ).where(db.Auction.id == auction_id).gino.status()

    # Уведомление победителю в ЛС бота
    if winner_form_id:
        winner_user_id = await db.select([db.Form.user_id])\
            .where(db.Form.id == winner_form_id).gino.scalar()
        await bot.api.messages.send(
            user_id=winner_user_id,
            message=(
                f'🏆 Вы выиграли аукцион «{auction.title}»!\n'
                f'Ваша ставка: {top[1]}. Обратитесь к организатору.'
            ),
            random_id=0
        )


async def _schedule_auction_close(auction_id, delay_seconds):
    await asyncio.sleep(delay_seconds)
    await _finish_auction(auction_id)

Весь код асинхронный — бот, юзербот и таймеры работают параллельно в одном event loop

Фреймворк для VK Bot API и User API — обработка сообщений, callback-кнопки, raw-события стены
